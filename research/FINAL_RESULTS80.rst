原版共 312 个误报，C20 为 191 个，减少 121 个。每轮均逐查询比较
Boolean、TOI、output_tolerance 的全部 24 字节。仅允许有布尔真值

使评测失败，未将门槛降为只比较布尔结果。

没有声称独立测得绝对 TOI 误差。tolerance=1e-6 是原算法距离容差，
不应解读为绝对碰撞时间误差上限。

数值保守性依据
--------------

详细论证分别位于 NUMERICS.rst 和 CONTINUED_NUMERICS.rst，主要为：

* 相同子表达式复用、精确二进制倒数、内联和队列存储修改保持原来的
  操作顺序、精确整数值和堆顺序，不增加舍入误差。
* swept AABB 仅做端点 min/max 和严格比较。线性运动顶点与几何体
  的凸组合均处于端点坐标范围内，严格分离可证明整个时间段无碰撞。
* Bernstein 证书用向外舍入区间包含共面行列式的四组系数；同一严格
  符号排除整个时间区间的共面性，从而排除碰撞。无法证明时继续 BFS。
* 投影证书包含任意有限轴上全部端点的精确投影。运动几何体位于其
  端点凸包内，所以严格分离的投影界可证明无碰撞。轴的构造允许舍入，
  因为任何实际存储的有限分离轴都是有效证书；投影值本身必须向外包围。
* C19 将原来的 filter*delta^3 逐项向上舍入。非负性保证每一步的上界
  可向后传播，最终值不小于该数学公式的精确值。使用实际编译出的
  函数，在 4,096 组二进制输入和四个误差系数组合上进行了 16,384 项
  Python Fraction 精确有理数上界检查，全部通过。

新几何剔除仅在 minimum_separation=0 的 BFS 路径启用；不确定情况
回到原求解器。三轮两版日志均记录 MXCSR=8064、最近舍入、FTZ=0、
DAZ=0，满足向外舍入与算术等价论证的环境要求。零漏检测试是验证
证据的一部分，未被用来代替上述数学依据。

环境、数据与审计
----------------

* 同一台 Intel Core Ultra 7 265KF，Windows 11 10.0.26200，MSVC
  19.44.35227.0，Release /O2 /Ob2 /DNDEBUG，CCD 库 /arch:AVX2，
  默认 precise 浮点设置，不开启 fast-math 或 FMA 重结合。
* double，BFS，tolerance=1e-6，max_iterations=1000000，
  minimum_separation=0，t_max=1，err=(-1,-1,-1)，no_zero_toi=false。
  OMP/MKL/OpenBLAS 线程数均为 1，计算线程绑定逻辑 CPU 0。
* 原版核心从 v1.0.6 提取，19 个源文件再次逐字节核验。原版与候选
  使用同一评测入口和相同数据顺序。baseline 专用运行脚本的原版
  检查保留，候选使用明确独立的 research.py 入口。
* 原数据只读，沿用固定版本 CCD-Query-IO 的 GMP 读取器转换为
  相同 double。最终计时结束后重新核验了全部 10,406 个全量/
  子集缓存文件，共 11,986,844,000 字节，SHA256 全部匹配。
* 原 baseline 工作树保持干净；所有研究代码、缓存和新增结果均在
  Tight-Inclusion-autoresearch 中。两工作树脚本仅有检出换行差异。
* 中途 C08 曾被 Smart App Control 拒绝，失败证据未删除。用户恢复
  目标后检测到策略状态为 0，原文件哈希不变且成功执行。最终对照
  两版均在恢复后的同一环境运行；代理未修改系统安全设置。

从 D:/ly/DGP-Autoreasearch/Tight-Inclusion-autoresearch 运行，复算
现有结果、不启动 CCD::

    python research/research.py summarize --prefix final80-c20 --target-reduction 0.80

使用已测程序与现有数据，重新交替运行六轮，需选择新的 prefix::

    python research/research.py paired --prefix c20-reproduction-01 --candidate-snapshot research-results/runs/c20-subset --allow-fp-removal --target-reduction 0.80

从当前源码重建已配置的同机 Release 入口::

    cmake --build build-autoresearch-sample --config Release --target research_reference research_candidate research_equivalence --parallel 8

新建构建目录时，先用 research/research.py init 提取原版，再按保存
的 CMakeCache.txt / results.json 配置相同依赖、double 和
TIGHT_INCLUSION_RESEARCH=ON。缓存若需重建，使用 prepare --workers 8，
不要覆盖原 baseline 数据或已有研究输出。生成 config.hpp 以实际
CMake 配置为准。NumCCD 的布局有变化，使用源码版本时需重编译
依赖该结构的代码。C20 最多为 VF/EE 分别保留约 3.75 MiB 队列容量，
合计每计算线程约 7.5 MiB；超过上限的容量照常释放。
